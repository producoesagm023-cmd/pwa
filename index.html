BT Radar

Este app usa a Web Bluetooth API do Chrome OS para detectar sinais BLE ao redor. Para ver RSSI em tempo real de todos os dispositivos (varredura passiva), ative em chrome://flags/#enable-experimental-web-platform-features e reinicie o navegador. Sem isso, o navegador abrirá o seletor nativo do Chrome OS para você escolher um dispositivo por vez. A "posição" no radar é aproximada: o ângulo é apenas ilustrativo (Bluetooth não informa direção), a distância vem da força do sinal (RSSI).
Pronto para escanear.
Centro = este Chromebook. Anéis = 1m / 3m / 6m / 12m+ (estimado por RSSI)
